Вход по ссылке из бота

  1. Откройте бот и отправьте команду /admin.
  2. Перейдите по ссылке из ответа — она действует 10 минут.
  3. Вход в браузере держится 12 часов.

Ссылка выдаётся только владельцу сервиса. Кнопка «Выйти на всех устройствах» в личном кабинете закрывает и панель.
