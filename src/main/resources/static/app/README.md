# Mini App

Telegram WebApp — витрина и личный кабинет подписчика. Отдаётся Spring Boot как статика.

## Структура

```
src/main/resources/static/app/
├── index.html
├── style.css
├── script.js
└── README.md
```

Spring Boot auto-serves `static/` — файлы доступны по пути `/app/*` на том же origin-е, что и API.

## Дизайн-система

Все токены — в начале `style.css`, в `:root`. Правило одно: новые значения берутся
из шкал, а не подбираются на глаз.

| Что | Токены | Комментарий |
|---|---|---|
| Отступы | `--s-1…--s-7` = 4 · 8 · 12 · 16 · 24 · 32 · 48 | других отступов в файле нет |
| Кегли | `--fs-1…--fs-8` = 11 · 12 · 13 · 15 · 17 · 20 · 28 · 40 | 16px остаётся только у `input` — иначе iOS зумит страницу при фокусе |
| Радиусы | `--r-sm` 10, `--r-md` 14, `--r-lg` 20, `--r-pill` | |
| Поверхности | `--bg` → `--surface` → `--surface-2` → `--surface-3` | слои разделяет фон, а не рамка |
| Текст | `--text` / `--text-2` / `--text-3` | все три проходят WCAG AA (≥4.5:1) и на `--bg`, и на `--surface` |
| Акцент | `--accent`, `--accent-2`, `--accent-tint`, `--accent-ink` | зелёная ЗАЛИВКА — только у главного действия блока |

Шрифты: **Golos Text** (текст), **Unbounded 700** (wordmark, число дней, цифры
статистики), **JetBrains Mono** (ссылки, id, адреса). Меняя набор, поправить и
список в javadoc `SecurityHeadersFilter#applyMiniAppCsp`.

Две фоновые анимации — дождь «ORCHESTRA» и встречные полки с пунктами подписки.
Обе намеренно приглушены, ручки в одном месте каждая:

| Что | Где | Значение |
|---|---|---|
| Прозрачность дождя | `script.js :: spawnRainColumns` | `0.07 + (i % 3) * 0.015` |
| Скорость дождя | там же | `40 + (i * 4.7) % 16` секунд на проход экрана |
| Плотность дождя | там же | одна колонка на 68 px ширины, от 5 до 11 |
| Скорость полок | `script.js :: renderServices` | `startMarquee(…, 20, 'left')` и `17, 'right'` px/с |

Обе выключаются системной настройкой «меньше движения» (`REDUCED_MOTION` в
`script.js` + блок `@media (prefers-reduced-motion: reduce)` в конце `style.css`);
Telegram эту настройку прокидывает в WebView. Полки в этом режиме не пропадают —
листаются пальцем.

## Как открыть локально

1. Поднять приложение: `docker compose up --build` (или `mvn spring-boot:run`).
2. Открыть <http://localhost:8080/app/>.

Вне Telegram `window.Telegram.WebApp` не существует, поэтому `script.js` подставляет
демо-данные (см. `DEMO_ME` в начале файла) — витрина, экраны и анимации проверяются
в обычном браузере, без бота и без оплаты. Реальные данные приходят только внутри
Telegram: клиент подписывает `initData`, а сервер проверяет подпись
(`TelegramInitDataValidator`).

## Как отдать наружу

Файлы статические, поэтому отдельного сборочного шага нет — реверс-прокси перед
приложением должен пропускать `/app/*` и `/api/*` на тот же origin, что и Mini App.
Разные origin у страницы и API означают preflight на каждый POST; список разрешённых
источников — в `WebAppCorsConfig`.
